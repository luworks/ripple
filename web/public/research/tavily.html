Tavily Feature Guide

5 core capabilities, 4 management endpoints, and several ways to connect. Based on the docs.tavily.com index, OpenAPI spec, and changelog (read 2026-11-14).

Which one to use

Sources unknown → Search  |  URL known → Extract  |  Explore a site → Map → Crawl  |  Need a cited answer → Research

Core capabilities

CapabilityWhat it doesKey parametersCost (credits)
SearchWeb search that returns LLM-ready relevant snippets search_depth (4 speed/quality levels); time_range; topic (news / finance); include_domains with prefer or restrict; max_age_hours for cache freshness; exact_match; language, country 1 per call
advanced: 2
ExtractClean markdown content from given URLs query keeps only relevant chunks; extract_depth=advanced gets tables; timeout 1–60 s 1 per 5 URLs
failures free
MapLists a site's pages without reading them max_depth, limit; select_paths (regex); instructions in natural language 1 per 10 pages
with instructions: 2
CrawlMap plus page-by-page extraction of a whole site Map parameters plus Extract parameters; up to 150 s per call ~3 per 10 pages
ResearchAsync, cited research report model (mini / pro / auto); output_schema for structured JSON; files (up to 5); stream for live progress mini 4–110
pro 15–250

Management endpoints

EndpointWhat it does
/usageRemaining credits. Limited to 10 calls per 10 minutes
/logsPer-request logs, filterable by date, endpoint, and key. Paid plans only
/feedbackTell Tavily which results were useful to improve ranking. Free, beta
EnterpriseGenerate or deactivate keys in bulk; organization-wide usage

Header X-Session-Id groups requests from one conversation; X-Human-Id identifies the end user.

Ways to connect

  • SDK: Python tavily-python, JS @tavily/core
  • CLI: npx @tavily/cli init also installs skills and MCP for Claude Code, Codex, and Cursor
  • Remote MCP: claude mcp add tavily --transport http https://mcp.tavily.com/mcp/
  • Keyless: add header X-Tavily-Access-Mode: keyless; Search and Extract are free but rate-limited
  • x402: agents pay per call in USDC, advanced search $0.01 per call, no account needed
  • 50+ framework integrations (LangChain, LlamaIndex, CrewAI, Vercel AI SDK, n8n, …), all wrapping the 5 endpoints above

On every plan, crawl and map are capped at 100 requests/min and research at 20. Over the limit returns 429; wait for Retry-After before retrying.

Tavily vs. Telem

  • Everyday search and page reading go through Telem
  • Crawl, Map, and Research are not in Telem; call Tavily directly
  • For fine-grained options like max_age_hours, exact_match, or prefer, calling Tavily directly is simpler
  • Research output_schema returns structured data, good for bulk enrichment
